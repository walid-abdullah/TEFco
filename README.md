## ⚡ Executive Platform Overview

**The Editly Foundry Co.** is a production-grade, high-performance web platform built to power an international video post-production agency. Architected with **Next.js 15 App Router**, **React 19**, and interactive **Three.js WebGL**, the system integrates enterprise lead generation pipelines, real-time quote generation, and automated WhatsApp/Email CRM workflows.

- 🌐 **Live Production URL:** [https://editlyfoundry.vercel.app](https://editlyfoundry.vercel.app)
- 🚀 **Performance SLA:** 48-Hour High-Retention Turnaround Pipeline
- 🎯 **Primary Engine:** Direct-Response Client Acquisition & Automated Meta Cloud API Routing

```yaml
Architecture: Next.js 15 (App Router) + React 19 SSR / CSR Hybrid
```

## 💻 Local Development Setup

Clone the repository and run the development environment:

```bash
# 1. Clone the repository
git clone https://github.com/walid-abdullah/The-Editly-Foundry-Co.-Agency-Site-.git

# 2. Enter the directory
cd The-Editly-Foundry-Co.-Agency-Site-

# 3. Install dependencies
npm install

# 4. Configure Environment Variables (.env.local)
cp .env.example .env.local

# 5. Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

---

## 🔐 Environment Variables Configuration

Create a `.env.local` file in the root directory:

```env
# Meta WhatsApp Cloud API (Production)
WHATSAPP_PHONE_NUMBER_ID=your_phone_number_id
WHATSAPP_ACCESS_TOKEN=your_permanent_system_access_token

# Email & SMTP Routing
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=theeditlyfoundry@gmail.com
SMTP_PASS=your_app_password

# Public Canonical URL
NEXT_PUBLIC_SITE_URL=https://editlyfoundry.vercel.app
```
